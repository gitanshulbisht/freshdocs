Installing AcmeDB

Prerequisites

AcmeDB runs on Linux x86_64 hosts with at least 4 GB RAM. Docker is supported for local development.

Docker install (quickstart)

docker run -d -p 5432:5432 --name acmedb \
  acme/acmedb:latest --auth root:secretpw

The server starts in ~5 seconds and listens on port 5432. The default superuser is root.

acmectl CLI

Install the CLI with: curl get.acme.dev/cli | sh. Then run acmectl cluster create my-cluster --size m5.large to provision a managed instance.
