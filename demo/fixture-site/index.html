AcmeDB Documentation

AcmeDB is a distributed SQL database built for modern, globally distributed applications. It offers strong consistency, automatic sharding, and a PostgreSQL-compatible wire protocol.

Key concepts

An instance is a logical cluster of database nodes. An instance owns one or more databases. Databases contain schemas, which contain tables. Connections are made with acme://HOST:5432/dbname.
