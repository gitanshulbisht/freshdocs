AcmeDB CLI Reference

The acme CLI manages instances, databases, and runs SQL.

acme db create

acme db create mydb --owner admin@example.com --size 10GB

Creates a new database owned by the given user. Available sizes: 1GB, 10GB, 100GB.

acme sql

acme sql mydb "SELECT count(*) FROM users;"

Runs a read-only query and prints results as a table.

acme admin logs

acme admin logs my-cluster --tail 100 --follow

Streams the last 100 log lines; use --follow to tail live.
