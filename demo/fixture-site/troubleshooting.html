Troubleshooting

Connection refused on port 5432

Ensure the container is running (docker ps). If it exited, run acme admin restart my-cluster and check the logs.

Error PIT-123: quorum lost

This occurs when a majority of nodes are unavailable. Restart the affected node with acme admin restart node- and verify recovery via acme admin logs --follow.

Slow queries
