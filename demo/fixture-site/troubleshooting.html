Troubleshooting FixtureDocs

The server won't start

If the server fails to start, check that port 9200 is free: 

lsof -i :9200

You can change the port by setting FIXTUREDOCS_PORT before launch.

Search returns no results

An empty search result usually means the document was never indexed. Re-index with fixturedocs index --force and try the query again.
