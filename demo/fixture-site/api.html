FixtureDocs API Reference

FixtureDocs exposes a small HTTP API. The base URL is http://localhost:9200 by default.

GET /health

Returns a health check payload: 

{"status": "ok", "version": "1.4.2"}

POST /index

Indexes a document. The request body must include a title and a body field. Returns the assigned document id.

GET /search?q=

Searches the index and returns the ten best matches ranked by relevance.
