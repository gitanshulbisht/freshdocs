Query Syntax

AcmeDB supports a PostgreSQL-compatible SQL dialect. All statements are transactional.

Selecting rows

SELECT name, balance FROM accounts WHERE balance > 1000 ORDER BY balance DESC LIMIT 10;

Filtering uses standard WHERE with AND/OR. Predicate pushdown is automatic across shards.

Joins

Inner, left, and right joins are supported. Cross-shard joins incur a network round-trip per participant shard.
